# A Photovoltaic Architecture Achieving Cell-Level Decoupling

Simulation code for **A Photovoltaic Architecture Achieving Cell-Level Decoupling via a Time-Division Multiplexed Shared Converter**.

## Overview

This repository provides the Python simulation code for evaluating the proposed cell-level decoupled photovoltaic architecture.

The simulation includes four scenarios:

1. Mixed partial shading
2. Irradiance variation
3. Cell aging mismatch
4. State-of-charge (SOC) balancing



## Requirements

The code requires Python 3 and the following packages:

```bash
pip install numpy scipy matplotlib
```

## Usage

Run the simulation directly with:

```bash
python main.py
```

The script automatically executes all four simulation scenarios.
